原始介面與授權

內嵌介面直接使用 Service Harbor 的 HTML、CSS 與 JavaScript，來源版本為 8ffebf6。保留原版功能頁與互動，再加入展示資料層、簡報導覽與重點框線；沒有安裝或執行原專案後端。

展示 API 與日誌串流由瀏覽器記憶體模擬，不發出真實 API／SSH 請求。重新載入或重設展示後，操作內容會回到初始範例。外部網站連結不會從展示介面開啟。
