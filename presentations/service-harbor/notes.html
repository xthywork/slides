Service Harbor 簡易摘要講稿

開場：今天介紹 Service Harbor。它把不同電腦上的服務集中到同一個網頁，方便查看狀態、操作服務與查找問題。先看圖像動畫理解用途，再視需要切換原版介面操作；主機與數值都是展示範例。

1｜總覽：先找到需要注意的地方

圖解：分散的服務 → 管理中心 → 重點總覽。

總覽會整理服務異常、主機與連線結果。可以先從這裡找到有問題的項目，再點進詳情；常用服務則能放在最愛。

2｜服務清單：集中查看與篩選

圖解：完整服務清單 → 挑你想找的 → 留下符合的服務。

每張卡片代表一個服務，可以依名稱、狀態、分類或主機篩選。狀態來自系統的查詢結果，不是固定寫在卡片上的文字。

3｜服務詳情：把相關資訊放在一起

圖解：選一張服務卡 → 打開看細節 → 狀態、操作、紀錄。

點開服務，可以看到狀態、檢查時間、工作紀錄和操作按鈕。管理主機負責向本機或遠端電腦取得這些資訊。

4｜啟停控制：確認後才執行

圖解：你按重新啟動 → 先確認再執行 → 服務重新運作。

啟動、停止或重新啟動前，先確認目標服務與主機。後端再檢查權限，執行允許的動作，最後把結果回傳到畫面。

5｜日誌：找出發生問題的線索

圖解：服務寫工作日記 → 新紀錄一直送來 → 把錯誤行找出來。

日誌就像服務的工作日記，可以搜尋關鍵字、篩選錯誤或暫停追蹤。新紀錄會持續傳回畫面，幫助我們判斷問題，但不會自動修復故障。

6｜連線檢查：有運作，不一定連得上

圖解：管理中心 → 試著接通入口 → 看連通結果。

管理主機會嘗試連接指定的網路入口，也就是 Port。能連上不代表網站所有功能都正常，所以要搭配服務狀態與日誌一起看。

7｜主機管理：連接其他電腦

圖解：你的管理中心 → 建立安全連線 → 另一台服務電腦。

把其他 Linux 電腦加入後，就能在同一個介面管理它們的服務。遠端連線使用 SSH，並且需要先設定登入金鑰與操作權限。

8｜指紋核對：確認連到正確的電腦

圖解：不確定是哪台電腦 → 比對兩份身分資料 → 確認信任。

主機指紋就像電腦的身分識別。實際使用時，要從可信來源核對一致，才確認信任；金鑰負責登入身分，指紋負責確認對方是誰。

9｜新增服務：建立管理紀錄

圖解：填入服務資料 → 先看卡片預覽 → 加入服務目錄。

填入服務所在主機、名稱、網址與檢查方式，右側就能預覽卡片。加入的是管理清單，不會替我們安裝或啟動原本的軟體。

10｜持續追蹤：按需要更新

圖解：選一個要觀察的服務 → 設定更新方式 → 回總覽看追蹤。

Live 每三秒更新目前選取的項目；鈴鐺則每五秒檢查，並可設定追蹤多久。關閉網頁會停止查詢，日誌也有自己的暫停控制。

11｜設定交換：保存與搬移清單

圖解：選擇要帶走的清單 → 打包成設定檔 → 到另一個環境匯入。

可以把全部、分類、最愛或單一服務匯出成 JSON 設定檔，再預覽後匯入。匯出不包含密碼、私鑰與主機信任資料，也不能取代完整備份。

12｜整體原理：要求、處理、回傳

圖解：你的瀏覽器 → 管理中心處理 → 服務與設定。

瀏覽器提出要求，由管理主機檢查登入與權限，再透過系統工具或 SSH 取得結果，最後整理回畫面。它的核心就是把服務資訊和操作入口集中在一起。

13｜圖像流程：管理中心幫你去問，再把答案帶回來

先指左邊：這是你和瀏覽器。再指中間：這是 Service Harbor，就像管理中心。最後指右邊：網站在這台電腦上運作。按播放，跟著綠色箭頭把問題送出去，再跟著藍色箭頭把答案帶回來；狀態最後就出現在你的畫面。管理中心和服務也可以在同一台電腦上。

結尾提醒：正式使用以可信任的私人網路為主。預設 HTTP 沒有傳輸加密，跨網路連線需另設 VPN 或受控的 HTTPS 入口。
